## Nội dung

Repository gồm 2 bài React Native:

### 1. ProductApp_Midterm
Ứng dụng Product App gồm các chức năng:
- Hiển thị danh sách sản phẩm
- Gọi API GET
- Hiển thị loading bằng ActivityIndicator
- Component ProductCard
- Hiển thị dạng 1 cột / 2 cột
- Chuyển đổi layout bằng Switch
- Pull to Refresh
- Test component bằng Jest

### 2. BookStore_Week5_10
Ứng dụng BookStore gồm các chức năng:
- Điều hướng giữa các màn hình
- Hiển thị danh sách sách
- Tìm kiếm và lọc sách
- Đăng nhập / đăng xuất
- Giỏ hàng
- Danh sách yêu thích
- Đánh giá sách
- Thanh toán
- Xem đơn hàng
- Cập nhật thông tin người dùng
- Pull to Refresh
- Sử dụng json-server làm API giả lập
