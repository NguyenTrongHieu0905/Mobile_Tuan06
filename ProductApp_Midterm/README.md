# Product App - Bài giữa kỳ / Ôn tập React Native

## Chạy
```bash
npm install
npx expo start
```

Đã hoàn thành SafeArea, GET + loading, FlatList, ProductCard, row/tile, Switch 1/2 cột, key theo numColumns, columnWrapperStyle, pull-to-refresh, test 4 nhóm và bài mở rộng "Chỉ còn hàng".

App đang dùng DummyJSON để chạy ngay. Khi nộp bài, nếu giảng viên yêu cầu API do sinh viên tự tạo, thay `API_URL` bằng endpoint MockAPI/Mockaroo và chỉnh/bỏ phần map tùy cấu trúc dữ liệu.
